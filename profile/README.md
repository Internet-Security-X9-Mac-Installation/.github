## What Sits Behind The X9 Name

Intego did not build one product with a long feature list; it built two and sold them together. VirusBarrier
handles anything stored: Mac viruses, Windows and Unix strains, macro viruses embedded in Word and Excel
documents, Trojan horses, worms, spyware, adware, dialers, hacking tools, keyloggers and scareware — the
fake security programs that charge you to remove an infection they invented. NetBarrier handles anything
transmitted, watching which applications are talking and to whom.

Splitting the work that way matters because the two failure modes look nothing alike. A file can pass every
signature check on arrival and misbehave a fortnight later. A perfectly legitimate application can be
chattier with the internet than you ever agreed to. One engine cannot see both.

## What Arrives, What Runs, What Leaves

**Arriving.** Mounted external drives are scanned automatically, archives are opened and inspected before
you unpack them, mail is checked in the popular email clients, and a connected iPhone or iPad has its
document directories examined for anything it might be carrying. Windows malware is flagged too — not
because it can run on your Mac, but to stop your Mac quietly acting as a courier to a colleague's PC.

**Running.** Round-the-clock real-time protection watches file activity continuously rather than waiting for
a scheduled sweep, and application behavior analysis flags a running program acting strangely even when no
signature matches it. On-demand scans come in two sizes: a quick pass for daily reassurance, a full pass
when you want every corner of the disk covered.

**Leaving.** The active application list names every program currently using bandwidth and separates
incoming traffic from outgoing. That is where rogue software gives itself away — the zombie sending on
command, the backdoor accepting connections, the app exporting more of your confidential information than
its job requires. You can also decide how the Mac speaks to specific local devices and configure the primary
channels running to and from the internet and the local network.

## A Week Of Ordinary Use

1. Day one is the loud one. Let the first full sweep finish rather than cancelling it, and expect the
   network side to introduce most of your software as each program asks for permission.
2. Answer those prompts honestly instead of clicking through them. Allow or deny per application, per domain
   or per local device, and the volume collapses within about a day.
3. Choose a default reaction to detections: attempt an automatic repair, quarantine for a decision later, or
   ask you case by case. There is no wrong answer, only an unchosen one.
4. Set the timetable. Scheduled scans exist so that nobody has to remember; a nightly quick pass and a
   weekly full pass covers most single-machine setups.
5. Read the history logs once at the end of the week. Detections, repairs and quarantined items are all
   recorded, and a quiet log is itself information.

## Settings Worth Changing Immediately

Mark trusted folders so repeat scans stop re-reading enormous directories that never change — this is the
single biggest speed win available. Turn on email notification of detections if you are ever away from the
desk. Create the home, public and work profiles rather than living on one, then leave automatic profile
switching enabled so a café connection is not treated like your own router. A firewall app mac setup that
never adapts to the network is only doing half the job.
